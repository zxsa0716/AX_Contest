한국 코스피 상장기업의 온실가스 공시 신뢰성 3중 검증
— GIR 법정 배출량 · ESG 자체보고 · Sentinel-5P 위성 NO₂/SO₂ 불일치 패턴 분석 및
ESG 의무공시 검증체계 설계
기업이 정부에 신고하는 법정 온실가스 배출량(GIR)과 투자자에게 공개하는 ESG 자체보고 Scope 1 배출량, 그리고 Sentinel-5P 위성이 측정하는 대기 중 NO₂·SO₂ 신호를 3중 비교해 공시 불일치 패턴을 분류하고, ESG 의무공시 도입 시 검증 우선순위 프레임워크를 제시한다.
분석 대상: 코스피 200 ∩ GIR 목표관리제 교집합 기업 (목표 60–80개사) 분석 기간: 2019–2023년 (5개년 패널) 위성: Sentinel-5P TROPOMI L3 NO₂ + SO₂ 플랫폼: Google Earth Engine · Python

01 핵심 연구 질문 3개
RQ 1 — 공시 신뢰성
한국 상장기업의 GIR 법정 보고와 ESG 자체보고 Scope 1 배출량은 체계적인 괴리를 보이는가?
괴리의 방향·크기·연도 추세, 기업 특성(규모·업종·검증기관 여부)과의 연관성 분석. ESG 의무공시 논의 시작 전후 괴리 변화 여부 포함.
방법: 괴리율 산출 → Isolation Forest + LOF 앙상블 이상탐지 → 패널 회귀
RQ 2 — 위성 독립 검증
Sentinel-5P TROPOMI NO₂·SO₂ 신호가 GIR 및 ESG 보고 배출량과 시간적 일관성을 보이는가?
세 측정값(GIR·ESG·위성)의 연도별 증감 방향 일관성을 분석. 불일치 패턴을 4유형(A·B·C·D)으로 분류하고 어느 보고값이 실제 배출 활동에 더 가까운지 판별.
방법: GEE NO₂/SO₂ 추출 → 시계열 방향 일관성 → 군집 분류
RQ 3 — 정책 설계
ESG 의무공시 검증 체계 설계 시 위성·GIR 데이터 기반 우선순위 모형은 어떻게 구성되어야 하는가?
패턴 분류 결과를 바탕으로 공시 검증 자원이 우선 투입되어야 할 기업·업종·연도를 특정. KEITI 환경책임투자 플랫폼과 연계되는 구체적 지표 설계안 제시.
방법: 우선순위 매트릭스 → 정책 시나리오 3종 제안

01
데이터 수집 및 통합
GIR 명세서(공공데이터포털 CSV 직접 다운로드), KRX ESG 포털 보고서 PDF 크롤링(Selenium), DART Open API 재무 데이터 수집, GEE Python API로 NO₂·SO₂ 위성 시계열 추출. 수집 순서: A(가장 쉬움) → B(가장 오래 걸림) → C/C-2 → D 병렬 수집.
데이터 전처리 공공데이터포털 KRX ESG포털 Google Earth Engine
02
전처리 — 4개 핵심 과제 해결
① 기업명 매칭: RapidFuzz fuzzy matching (유사도 임계값 0.85) + 사업자번호 교차 검증 + 수동 검수. 최종 60–80개사 확정.
② Scope 통일 (핵심): Scope 1 직접 연소 배출만 비교. GIR = Scope 1 그대로, ESG = GRI 305-1 항목만 추출. 조직 경계(연결/별도) 플래그 추가해 통제변수화.
③ 결측치: MICE(Multiple Imputation by Chained Equations). 보고서 미발간 연도 대응. 민감도 분석으로 검증.
④ 이상값: IQR + 기업 합병·분할 연도 플래그, 코로나 2020 주석 처리. 조정 사유 전체 문서화.
데이터 전처리 Scope 통일 (핵심 난관) MICE RapidFuzz
03
괴리 지표 설계
괴리율(%) = (ESG 자체보고 − GIR 실제) / GIR 실제 × 100

① 절대 괴리 (tCO₂eq): 규모 효과 파악용
② 상대 괴리율 (%): 기업 간 비교 가능 단위
③ 방향성 구분: 과소 신고(음수) vs 과대 신고(양수) 분리 분석
④ 연도별 추세: 2019–2023 패널 — ESG 의무공시 논의 전후 변화
⑤ 업종별 비교: 에너지·철강·화학·기타 — 어느 업종에서 괴리가 심각한지
분석기법 타당성 패널 구조 방향성 분리
04
이상탐지 — 고위험 기업 식별 앙상블
Isolation Forest (contamination=0.1): 다변량 이상탐지. 입력 — 괴리율·배출규모·연도·검증여부. 비지도학습 → 라벨 불필요.
LOF (Local Outlier Factor) (k=20): 밀도 기반. 국소 밀도 비교로 희소 구역 기업 탐지.
앙상블 전략: 두 모델 모두 이상으로 판정한 기업 = "고위험 공시 불일치 기업"으로 최종 분류. 단일 모델 대비 false positive 최소화. 심사에서 방법론 타당성 명확히 설명 가능.
분석기법 타당성 Isolation Forest LOF 앙상블
05
위성 3중 비교 — 인사이트의 핵심 (독창성)
방향 일관성 분석: 절대값 비교가 아닌 연도별 증감 방향(↑/↓) 일관성 검사. NO₂가 CO₂의 완벽한 대리변수가 아니라는 한계를 우회.

4가지 불일치 패턴:
패턴GIR 추세ESG 추세위성 신호해석
패턴 A ↑↑↑ 세 측정값 일관 — 정상
패턴 B ↑↓↑ ESG만 이탈 — 그린워싱 의심, 위성이 GIR 지지
패턴 C ↑↓↓ 위성이 ESG 지지 — GIR 과대 산정 의심
패턴 D ★ ↓↓↑ GIR·ESG 모두 위성과 불일치 — 가장 심각한 경우
패턴 D가 발견되면 논문 1편 분량의 발견. SO₂ 데이터를 NO₂와 교차 검증해 업종별 결과 견고성 확보. 국내 최초: 한국 코스피 기업 대상 3중 검증 연구 전무.
인사이트 독창성 NO₂ + SO₂ 방향 일관성 패턴 분류
06
패널 회귀 — 통계적 유의성 확보
괴리율ᵢₜ = α + β₁(lnAsset) + β₂(검증여부) + β₃(조직경계) + β₄(연도더미) + β₅(업종더미) + μᵢ + εᵢₜ

모형 선택: Hausman 검정으로 고정효과(FE) vs 확률효과(RE) 결정. 기업별 불변 특성 통제.
강건성 검정 3개: ① 업종별 클러스터 표준오차 ② 2020년 코로나 제외 재실행 ③ 괴리 정의 변경(절대값/방향 분리) 후 재실행.
추가 검증: 제3자 검증기관이 있는 기업의 괴리율이 유의하게 낮은지 검증 (검증 제도 효과성 평가).
결과의 유의성 고정효과 패널 강건성 검정 3종 Hausman 검정
07
XAI — 설명가능성 (연구 DNA 직결)
SHAP Values: 이상탐지 모델 및 회귀 모델에서 기업별로 어떤 변수가 괴리를 키웠는지 기여도 분해. 기업별 설명 가능 → 정책 타겟 명확화.

데이터 전처리
 단계 1–2
RapidFuzz fuzzy matching (임계값 0.85) + 사업자번호 교차검증. Scope 불일치 문제 명시적 해결 (Scope 1 단독 비교). MICE 결측치 처리 + 민감도 분석. 이상값 문서화 (합병·분할·코로나 플래그). "데이터를 제대로 다룰 줄 아는 사람" 신호를 심사위원에게 전달.
분석기법 타당성
 단계 3–4
괴리 지표를 직접 설계 (절대·상대·방향 구분). Isolation Forest + LOF 앙상블 — 비지도학습이라 라벨 불필요, 두 모델 앙상블로 false positive 감소 논리 명확. 단계 5의 위성 방향 일관성 분석은 절대값 단위 차이 문제를 완전 우회하는 방법론적 혁신.
인사이트 독창성
 단계 5
국내 최초: 한국 코스피 기업 대상 GIR·ESG·위성 3중 비교 연구 전무. 중국(Liu et al., 2020, Nature)·EU(ACP, 2024)는 있으나 한국 기업 공시 검증 맥락 적용은 처음. 패턴 D(GIR+ESG 모두 위성과 불일치) 발견 시 논문 1편 수준 기여. NO₂와 SO₂ 이중 위성 proxy로 업종별 결과 견고성 확보.
결과의 유의성
 단계 6–7
고정효과 패널 회귀 + Hausman 검정. 강건성 검정 3종(클러스터 SE·코로나 제외·괴리 정의 변경). SHAP + LIME으로 모델 판단 근거 설명가능하게 제시. 제3자 검증 제도 효과성 검증 포함. "p값과 계수만으로 끝내지 않고, 왜 그런지를 XAI로 설명"하는 구조.
활용 방안
 단계 8
KEITI 사업에 직접 꽂히는 제언 3개. "심사위원이 보면 당장 우리가 쓸 수 있다고 느끼는 구조." ESG 의무공시 시기가 확정되지 않은 상황이 오히려 강점 — "공시 도입 전에 검증 체계를 설계해야 한다"는 긴박성 증가.
05 정책 제언 3개 — KEITI 직결

환경책임투자 플랫폼 고도화

GIR-ESG-위성 연계 의무공시 설계
ESG 의무공시 도입 시 GIR 대조 검증 절차를 의무 포함하고, Sentinel-5P 수준의 위성 모니터링을 독립 검증 레이어로 제도화하는 시나리오 설계. EU CBAM 대응과 연계 가능.
06 방법론적 한계 및 대응 전략
한계 1 — 위성 공간 해상도 (3.5km)
한국 공단은 여러 기업이 밀집 → 특정 기업 NO₂ 신호 분리 어려움. 대응: 독립 입지 사업장 우선 선별 분석, 밀집 공단은 "기업 군집 단위"로 분석 단위 조정. 논문에서 투명하게 명시 → 오히려 신뢰도 증가.
한계 2 — NO₂ ≠ CO₂ 완전 등가 아님
NO₂는 연소 부산물로 화석연료 연소 활동의 신호이나, CO₂와 직접 환산 불가. 대응: 절대값 비교 아닌 연도별 증감 "방향 일관성" 분석으로 우회. SO₂ 추가 교차검증. 근거: Liu et al. (2020, Nature) 인용.
한계 3 — ESG 보고서 자발적 공시 편향
보고서를 내는 기업은 이미 ESG에 신경 쓰는 대기업 → 가장 나쁜 집단(보고서 미발간 기업)이 샘플에서 빠짐. 대응: 대형 배출 기업에 집중한 분석으로 명시, "보수적 하한 추정" 해석. 미발간 기업이 많을수록 실제 괴리는 더 클 것이라는 정책적 함의로 활용.
한계 4 — 인과관계 주장 불가
공시 괴리가 특정 결과를 "유발한다"는 인과 주장 대신, 불일치 패턴을 "기술"하고 검증 우선순위를 "도출"하는 프레임으로 설정. 대응: 분석 프레임을 처음부터 "우선순위 개입 지도"로 설정 → 반박 불가능한 구조.
07 연구자 DNA와의 연결 — 왜 이 사람이 해야 하는가
기후변화 인공위성 연구실 소속
GEE 환경 및 Sentinel 위성 데이터 처리 경험 보유 → 단계 5 위성 분석 직접 수행 가능. Sentinel-5P TROPOMI 처리 파이프라인 구현 역량.
시공간 GCN·XAI 연구 경험
도시열섬 GAT 모델·Urban Climate 논문 진행 중 → 이상탐지 앙상블 + SHAP/LIME XAI가 기존 연구 방법론과 자연스럽게 연결.
온실가스관리기사 자격 보유
GIR 배출량 산정 기준, Scope 정의, 국내 목표관리제·배출권거래제 체계 이해 → PDF 파싱 수치 해석 신뢰도 확보. 심사위원 앞에서 기술 설명 신뢰도 ↑.
기후정의·AR6 프레임 연구 경력
기후불평등 → 기후정의 → ESG 공시 신뢰성 문제로 연결되는 연구 스토리가 자연스럽게 이어짐. 정책 프레임 작성 역량.
