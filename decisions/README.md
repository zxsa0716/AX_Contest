# Decisions (ADR) — 의사결정 기록

이 폴더는 프로젝트 진행 중 내려진 주요 의사결정을 기록한다. 서브에이전트들은 서로의 컨텍스트를 공유하지 않으므로, 이 폴더가 **에이전트 간 공유 메모리** 역할을 한다.

## 파일명 규칙

- `YYYY-MM-DD-<topic-slug>.md` — 일반 ADR
- `handoff-YYYY-MM-DD-<from>-to-<to>.md` — 에이전트 간 인수인계 기록

## ADR 작성 규칙

1. 디렉터 전용. 서브에이전트는 직접 쓰지 않는다 (디렉터가 합의 후 기록).
2. 결정 시점의 **근거**와 **기각된 대안**을 반드시 포함.
3. 이후 결정이 이전 결정을 뒤집으면, 새 ADR을 작성하고 이전 ADR 상태를 `Superseded by <new-ADR>`로 업데이트.
